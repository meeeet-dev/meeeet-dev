## About me

I build things that live on screens of all sizes: web apps, mobile apps, and the APIs that keep them talking to each other.
Give me a Figma file and a deadline and I'll give you something that runs on iOS, Android *and* the browser.

- **Mobile:** Flutter & Dart, from pixel-perfect UI to app-store release
- **Web:** React, Next.js and TypeScript on the front; Node (Express/Fastify) and Laravel on the back
- **Payments & integrations:** Stripe, Razorpay, PhonePe, Firebase, shipping APIs
- **Currently:** taking on freelance projects and learning something new every week
- **Ask me about:** cross-platform apps, REST APIs, and turning "quick idea" into "shipped product"
- **Fun fact:** I have strong opinions about folder structure and weak opinions about tabs vs spaces
